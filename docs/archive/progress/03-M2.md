## 关键实现与设计差异

1. M1 桌面项目保留并按原 id 幂等登记 Host，不做删除或跨连接自动合并。桌面迁移新增 hostId、会话归属与草稿表，现有 SSH/文件/终端入口保留。
2. 每次构建安装到 `~/.agentdesk/host/versions/0.2.0-<wheel摘要前缀>-<plan前缀>/`，虚拟环境放在该版本的 `venv/`，current/previous 原子切换。与设计单列 venv 目录相比，版本资源集中，固定用户入口不变。
3. CLI 安装按任务 02 实测选择 SDK bundled Claude 和官方 Codex musl+bwrap；不采用全局 npm 或修改 PATH。资源由 `scripts/build/build_host_resources.py` 准备，不提交 wheel/二进制。
4. uv 0.13.5、Python 3.12.15+20261021、SDK 0.2.174、Codex 0.164.0 均固定。构建 manifest 包含摘要；Python 使用固定下载元数据交给 uv 原生管理和校验，依赖从 uv.lock 导出全量 hashes，pip 只用官方 PyPI。
5. 全局 seq 预留 1024 号段，重启跳过未使用尾号，允许间隙但不复用。这样 delta 无需逐条 SQLite 写入；2500 次序号分配只触发 3 次元数据更新的测试通过。
6. `sync.since` 末页增加活动 run.state 快照；新增 `host.prepareShutdown` / `host.cancelShutdown`，60 秒维护租约与 run.send 共用锁，避免其他设备在停机预检后启动运行。
7. Codex 追加使用 turn/steer；sandbox 命令不再带 linux 子命令。Claude 恢复使用 get_session_info；工具修改在成功结果后生成文件事件，不把调用意图当作修改成功。
8. Host 认证接口只准备 PTY 登录命令和显式退出；不经桌面收取/保存/转发账号令牌。模型目录只用于选择，不证明账号模型权限。

## 回滚与保留项

Host 当前入口：`/home/agentdesk-test/.agentdesk/host/current/`。保留 previous、测试版本、受管 Python 与缓存用于复核；没有自动删除旧版本或任务 02 材料。Host 的业务 SQLite 为 `.agentdesk/state/host.sqlite`，原生账号与会话记录不做备份或复制。

优先通过环境页「回滚」操作：会先拒绝活跃运行、校验目标，再停止/切链/重启。手工维护应先确认没有运行并停止 Host，再执行以下版本切回命令，不删除数据：

```sh
agentdesk_base="$HOME/.agentdesk/host"
test -L "$agentdesk_base/previous" && test -L "$agentdesk_base/current"
agentdesk_previous="$(readlink "$agentdesk_base/previous")"
test -x "$agentdesk_previous/venv/bin/python"
ln -s "$agentdesk_previous" "$agentdesk_base/current.rollback"
mv -Tf "$agentdesk_base/current.rollback" "$agentdesk_base/current"
AGENTDESK_CODEX_PATH="$agentdesk_base/current/bin/codex" setsid nohup \
  "$agentdesk_base/current/venv/bin/python" -m agentdesk_host </dev/null >/dev/null 2>/dev/null &
```

有 systemd 用户管理器时使用 `systemctl --user stop/start agentdesk-host.service`；测试服务器采用 setsid/nohup，未开启 linger。手工恢复只切版本，不回退业务数据库或覆盖原生账号配置；不兼容数据库迁移须另行评审，不能用旧库覆盖新事件。安装 staging、测试源与失败准备目录保留在测试用户家目录，清理需按具体归属目录确认，不整目录删除 `.agentdesk`。
