# 远程开发工作台前端布局与交互规范

版本：0.3\
日期：2026 年 10 月 26 日\
状态：Windows 首发，双执行方式与双 Agent 图形工作台

界面沿用 Pymss Studio 的桌面工作台结构：顶部标题栏、左侧窄导航、右侧页面容器，以及与主题统一的面板和表单。业务主视图采用项目与会话列表、聊天正文、底部输入框的布局，参考 CC Desk Tunnel、ChatGPT 和 Open WebUI 的常见聊天交互；资源、编辑器与终端作为辅助区域，保持清楚的执行目标和操作焦点。

本规范配合[需求文档](./远程开发工作台需求文档.md)使用。首版为个人多服务器、多设备使用，同时支持 Claude 和 Codex、远端项目与本机项目执行；先交付 Windows，后续逐步补齐 macOS 和 Linux。

## 1 技术与参考

前端采用 Vue 3、TypeScript、Vite、Naive UI、Pinia、Vue Router、vue-i18n 和 SCSS，包管理器使用 pnpm。Naive UI 组件沿用自动导入方式。桌面窗口使用 Tauri 2，系统能力由 Rust 层提供。

布局依据为 Pymss Studio 当前的 `App.vue`、`SideNav.vue`、`TitleBar.vue`、`global.scss`、`theme.ts` 和现有截图；音频业务页面、Logo、模型素材与业务文案不进入新工具。

## 2 桌面页面壳

| 区域 | 基线 | 内容 |
| --- | --- | --- |
| 标题栏 | 高 40px，固定顶部 | 应用标识、当前页面、拖动区与窗口按钮 |
| 主侧导航 | 宽 64px，标题栏下方通高 | 图标与短标签；业务上置，诊断和设置下置 |
| 通用页面 | 基线留白为上 26px、左右 32px、下 34px | 页面标题、说明、主要内容与操作 |
| 窗口 | 默认 1280 × 820，最小参考 980 × 680 | 最小窗口保留导航与主要工作操作 |
| 窄窗口 | 宽度小于 1180px 时，留白参考上 20px、左右 24px、下 28px | 减少非必要留白，优先保留工作区 |

桌面导航默认保持可见。Pymss 针对更窄页面隐藏侧导航的规则不直接应用于本工具的桌面核心流程。

```text
┌────────────────── 标题栏 40px ───────────────────┐
│ 导 │ 页面标题、当前连接与执行设备、页面操作       │
│ 航 │ ┌──────────┬────────────────┬──────────┐   │
│ 栏 │ │ 项目     │ 聊天正文       │ 文件与   │   │
│    │ │ 与会话   │ 工具与审批     │ 详情     │   │
│64px│ │ 列表     ├────────────────┤ 按需展开 │   │
│    │ │          │ 消息输入框     │          │   │
│    │ └──────────┴────────────────┴──────────┘   │
│    │      辅助终端与任务详情 按需展开             │
└────┴────────────────────────────────────────────┘
```

项目会话栏与可折叠文件栏是工作台内部区域，与全局导航区分。其他页面使用同一页面壳，不强行保留空资源栏。聊天区优先获得空间，不默认同时展开文件栏和终端。

## 3 导航与页面

| 导航 | 图标语义 | 页面重点 |
| --- | --- | --- |
| 工作台 | 对话或桌面 | 项目与会话、聊天、执行目标与辅助工具 |
| 连接 | 服务器或网络 | 配置列表、连接状态、创建连接 |
| 项目 | 文件夹 | 按设备与连接分组的项目、最近项目 |
| 任务 | 队列 | 安装、传输与已纳入范围的调度 |
| 环境 | 工具 | 分别展示 Agent 运行端与项目执行设备上的组件 |
| 诊断 | 日志或状态 | 连接阶段、重要错误与脱敏日志 |
| 设置 | 齿轮 | 外观、语言、快捷键、存储和连接偏好 |

导航项保持图标加短标签，活动项同时使用背景、边框或指示标识；焦点与选中状态分别可见。不会因为一个未来能力已出现在需求矩阵，就提前展示没有功能的导航页。

首次启动进入连接页，并给出新增连接操作。已有可用项目时恢复工作台选中状态；恢复布局不自动重建已经结束的终端或执行历史命令。

## 4 工作台布局

### 4.1 页面头部

左侧显示当前项目名称、连接名称和执行路径；右侧主操作为“新建会话”，辅助操作为打开文件栏和终端。当前设备、目录与在线状态必须可见，不能只藏在 Tooltip 或设置中。

模式名称采用“SSH 远程开发”和“云端 AI 操作本机”等描述执行位置的文案。用户切换工作台模式时选择目标项目，不把同一会话的执行目标静默替换。

连接错误区分控制连接与执行通道。只有通道异常时，也不能继续显示一个无条件的“已连接”。

### 4.2 项目与会话列表

建议初始宽度为 260px，可拖动调整并折叠；该值是新工具布局建议，Pymss 只提供页面壳基线。按运行服务与执行设备区分项目，项目下显示图形会话、Agent 类型和运行状态；支持搜索、收藏与归档入口。

最小窗口下可收起该列表，聊天头部保留当前项目与会话切换入口。选中会话后保留原生 Agent 类型，切换 Agent 创建新会话；不把现有历史静默换到另一个工具。

文件栏按需在右侧展开，包含当前目录、返回上级、刷新与文件列表。新建、删除、打包和下载集中到资源工具栏或右键菜单。删除确认显示完整目标；项目移除文案必须说明是否只清除索引。

### 4.3 辅助终端与编辑器

终端默认通过底部抽屉打开，不覆盖聊天输入框。用户可切换到专注终端视图。终端与编辑器使用有类型图标的工作标签，显示可辨识名称、运行或未保存状态、关闭按钮；多标签允许横向滚动，当前标签始终可见。

专注终端视图支持最多四分屏，分屏内展示标签内容。提供拆分、切换焦点和关闭分屏操作；关闭分屏保留其标签，关闭标签按资源类型释放资源。退出专注视图返回原聊天会话，不自动停止运行。

窗口缩放完成后发送终端尺寸更新，避免持续高频发送。终端自身滚动与页面滚动分离；用户向上滚动时新输出不强制拉回底部，提供返回最新输出入口。

终端采用等宽字体，并有完整的明暗配色；Naive UI 的页面字体和颜色不能直接覆盖终端控制序列的语义。

### 4.4 图形对话

本区域为默认工作台。项目与会话使用紧凑列表，中间为聊天正文；输入框固定在会话可用区域底部，不被全页面滚动挤出视口。正文在宽屏下控制阅读宽度，工具结果按需扩展。

正文、思考摘要、工具调用、审批与错误使用稳定的层级。工作步骤允许折叠，原始工具结果按需展开，避免连续的高密度嵌套面板。

输入区包含文本框、发送或停止按钮、Agent 标识和原生支持的模型与推理控制。正文支持 Markdown 与代码块复制；附件能力单独排期，不展示无功能的上传按钮。错误与审批保留在所属会话内。

原生终端通过明确入口打开，显示所属设备、项目与会话关系。未验证能共享上下文时，标明它是独立终端会话。

对话停止跟随滚动的规则与终端一致。停止、回答提问和审批显示对应状态；追加输入与推理细项按增强批次启用，未交付时不展示空入口，暂不可用的已有操作说明具体原因。

## 5 连接与环境页面

连接页沿用 Pymss 列表页的结构：标题与主要操作在上方，搜索或类型筛选居中，列表占据主要区域。列表显示名称、类型、目标、状态和最近使用时间。

新增连接先选择类型。SSH 表单填写地址、端口、用户名、密码与是否保存；代理服务表单填写服务地址、凭据与证书信任信息。表单内不混排另一种类型的必填项。

环境页先固定目标连接，再分别显示 Agent 运行端与项目执行设备的组件。云端 AI 操作本机时，Claude、Codex 和连接桥属于 Linux 运行端，本机 SSH 与脚本环境属于执行设备。把“检测”和“安装”作为不同动作；安装前的确认包含目标位置和操作内容，安装过程显示日志与取消入口。

服务连接状态与 Agent 登录状态分别显示。登录入口打开服务器上的官方登录终端，或转发官方授权链接与必要的交互；桌面不提供自有账号密码表单，不把 API key 作为使用已登录官方 CLI 的前置条件。

连接阶段显示为连续进度：服务身份校验、认证、运行代理检查、按需准备本机组件、通道建立、就绪探测。普通 SSH 浏览与终端不要求图形代理就绪；图形会话则单独展示 Agent 是否可用。

## 6 视觉规范

### 6.1 色彩与层级

主题以 Pymss 的语义变量体系为基线，颜色由主题统一注入，业务组件使用语义 Token。

| Token | 浅色参考 | 深色参考 | 用途 |
| --- | --- | --- | --- |
| surface | `#f4f6fa` | `#111317` | 应用背景 |
| surface 1 | `#fbfcff` | `#191c21` | 面板与标题栏 |
| surface 2 | `#eef2f7` | `#23272e` | 次级区域与输入背景 |
| 正文 | `#172033` | `#c9cdd4` | 主体文字 |
| 次级正文 | `#596579` | `#969da8` | 辅助说明 |

强调色参考 Pymss 的蓝、粉、天蓝与青绿主题方案。浅色保持克制的背景层次，深色使用平整表面和细边框；不可在深色模式保留浅色投影导致内容发灰。

### 6.2 字体与组件

应用字体采用与 Pymss 相同的 MiSans 字体体系或具备相同度量的系统回退，终端与代码区域使用等宽字体。字体资源纳入新工程前确认来源与分发方式。

面板、输入、下拉、对话框、消息与进度条优先使用 Naive UI。全局主题统一处理圆角、字号、边框与焦点；不在每个页面复制一套局部主题值。

主按钮用于当前页面的主要动作；终止或删除使用明确危险语义。图标和颜色不能替代文本状态。

## 7 焦点与键盘

1. 全局导航、资源栏、终端、编辑器与模态窗口分别管理焦点。
2. 弹窗打开时保存原焦点并限制焦点范围，关闭后回到原控件。
3. 终端获得焦点后，把不属于已声明全局快捷键的组合键交给 PTY；可在设置中查看冲突并修改。
4. 保存、关闭标签、切换标签、新建终端和分屏提供快捷键。最终键位在真实 CLI 兼容测试后确定，不直接照搬 TUI 的全部功能键。
5. 删除、安装与断开等确认窗口支持键盘操作，默认焦点避免落在不可逆动作上。
6. 剪贴板、粘贴与输入法不因主题切换、刷新目录或迟到的状态事件丢失焦点。

## 8 空状态与异常状态

| 场景 | 内容 | 操作 |
| --- | --- | --- |
| 尚无连接 | 说明连接类型及用途 | 新建连接 |
| 已连接但未选项目 | 显示当前执行设备 | 选择目录或打开最近项目 |
| 尚无终端 | 显示当前目录和可用工具 | 打开 Shell 或 AI CLI |
| 工具未安装 | 显示目标和所需依赖 | 查看安装方案 |
| 目录加载失败 | 保留原列表并标记失败 | 重试或返回上级 |
| 网络中断 | 分别显示连接、通道与运行状态 | 等待重连、停止重连或查看诊断 |
| 文件保存失败 | 保留完整编辑内容与错误原因 | 重试、另存或复制内容 |
| 原生上下文缺失 | 显示无法恢复的具体原因 | 检查存储、恢复备份或创建新会话 |

长任务使用区域内进度与可取消状态。Toast 只负责短反馈，重要错误和执行结果仍保留在对应对象详情，避免提示消失后失去处理入口。

## 9 布局验收

- 在 1280 × 820 和 980 × 680 下，标题栏、导航、连接目标和主要操作完整可用。
- 默认工作台以聊天为中心。窄窗口不同时占用固定宽度的项目栏、文件栏和终端；折叠后仍能切换项目、发送消息、审批和停止。
- 在系统 100% 与 150% 缩放下检查文本截断、弹窗按钮和终端可操作区域；长路径可复制。
- 深色、浅色和跟随系统主题均保持正文、禁用态、错误态和终端光标可辨认。
- 四分屏时每个区域可获得焦点和调整尺寸；可通过折叠资源栏或放大当前分屏恢复足够的操作空间。
- 用中文输入法、长路径、多标签和连续终端输出检查焦点与滚动，不以静态截图代替交互验收。
- 图形对话须验证输入框固定、历史加载、停止跟随、审批与原生终端关系，并覆盖两个 Agent 和两种执行方式。
