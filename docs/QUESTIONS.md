# 当前决策与待确认事项

本文说明当前开发约定。早期阶段问题及已被替代的方案保留在[历史决策记录](archive/QUESTIONS-M0-M3.md)，不再作为现行实现要求。

## 当前决策

1. **主要使用方式**：项目代码、工具链与官方 Agent 均位于远端 VPS，本机通过 SSH 使用界面。普通远程模式无需容器；本机执行通道和服务器隔离工作区是可选能力。
2. **模块边界**：Vue 负责交互，Rust 负责桌面能力、目标检查和 SSH，Python Host 管理服务器会话、事件与审批。历史 M0/M1 范围不限制当前 Host 功能。
3. **项目归属**：项目的连接、执行位置和运行方式在创建后固定。更换位置时新建索引；不自动移动文件或合并不同连接的同名项目。
4. **连接身份**：已有项目关联的连接不能修改 host/port/user。主机指纹变化拒绝连接；Host 身份用于识别同机连接，不据此自动合并索引。
5. **图形登录**：Host 的 `login.start` 管理官方登录过程，桌面转交实时提示；`login.respond` 和 `login.cancel` 操作原登录会话。授权链接和代码不进入聊天事件、日志或诊断。旧的仅返回终端命令的方案已经被替代。
6. **会话归档（A-01）**：真实会话默认归档并保留原生记录。只有 Fake Adapter 或官方元数据确认原生记录缺失时，才允许彻底删除镜像。
7. **本机执行权限（A-02 / A-03）**：需要当前连接中的项目授权和执行通道探测。Codex 保持已确认的第一档权限，不自动提升为 `danger-full-access`；本机项目拒绝 `plan`，因为 SSH 通道不能保证本机文件只读。按项目授权不构成对同一服务器用户下恶意进程的隔离。
8. **服务器条件**：普通模式以官方程序的实际探测结果为依据，并保留既定支持基线。单台旧系统运行成功不扩大全部版本的兼容承诺。可选容器模式另需通过 rootless Podman、cgroup v2 与实际运行边界检查。
9. **数据与版本**：桌面保留连接、项目归属和草稿，Host 保存会话、事件和审批。Host 使用单一数据库格式，新安装直接初始化；不兼容格式明确拒绝，不自动迁移。版本切换只允许目标 Host 验证通过的数据库，不通过回退程序版本来改变数据格式。

接口细节见[桌面基础契约](IMPLEMENTATION-CONTRACT.md)、[Host 契约](M2-CONTRACT.md)、[本机执行契约](M3-CONTRACT.md)和[隔离工作区契约](ISOLATION-CONTRACT.md)。

## 待确认事项

- 正式产品名、公开仓库地址与首个发行版本。目前继续使用 AgentDesk 和现有应用标识。
- Windows 安装包的签名、最终分发依赖许可清单，以及首发平台范围；不将已有平台代码等同于已完成对应实机验收。
- 用户登录后的真实模型任务验收，包括流式输出、工具、审批、停止、恢复和长时间运行。
- 完整的多设备项目索引合并和迁移规则；当前保持既有归属与幂等登记，不隐式迁移数据。

真实服务器操作的授权以当前任务为准，历史报告中的一次性授权不延伸到新的服务器、账号或系统变更。
